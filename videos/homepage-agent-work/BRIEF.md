# homepage agent work loop

## Intent

Create one short, silent product-motion loop for the public homepage hero. The
motion is evidence: two agents are visibly working in isolated worktrees, one
item finishes, and one decision becomes a clear “Needs you” request. The frame
must feel like the existing dongo product rather than a generic dashboard.

## Assets

No external media. Reconstruct the current dongo Overview from the repository’s
accepted design contract and existing UI components: near-black canvas, square
one-pixel borders, compact Switzer-style typography, monospace operational
labels, amber Attention, green active/completed state, and truthful canonical
Work identifiers.

## Customizations

- Keep the main product screen readable throughout; use only short vertical
  reveals, small cursor/progress movement, and one restrained state change.
- Show parallel work as host-created isolated worktrees coordinated by dongo;
  do not imply that dongo itself creates agents or wakes a stopped agent.
- Keep text comfortably legible when the 16:9 result is displayed at roughly
  600px wide on desktop and full-width on mobile.
- No narration, captions, music, decorative gradients, rounded dashboard cards,
  or ornamental 3D motion.

## Website context

The adjacent homepage copy is:

> dongo is Linear if it were built for agents, not humans.
>
> Stop following agent work across terminals and endless chats.
>
> See what your agents are working on, what’s done, and when they need you. Add
> work, answer questions, and give feedback from your phone or browser — while
> your agents keep working.

## Run shape

Autonomous short-form motion-graphics workflow. Build and verify the composition
without intermediate review; rendering remains gated by the final HyperFrames
preview-or-render choice.
